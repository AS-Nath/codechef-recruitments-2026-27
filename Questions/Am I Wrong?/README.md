# Am I Wrong? 

## Problem Statement

Chef's son has started learning decimal arithmetic at school. Every day, he solves a few addition problems and proudly shows his answers to his father.

Chef wants to make sure his son is getting the answers right. Given three decimal numbers A, B, and C, where his son claims that A + B = C, help Chef determine whether the answer is correct.

Since the numbers are written in decimal notation, Chef expects the calculations to follow ordinary decimal arithmetic exactly.

## Input Format

A single line containing three decimal numbers A, B, and C, separated by spaces.

## Constraints

- -100 <= A, B, C <= 100
- Each number has at most three digits after the decimal point.

## Output Format

Print `YES` if A + B = C, and `NO` otherwise.
