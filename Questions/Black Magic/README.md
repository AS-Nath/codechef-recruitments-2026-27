# Black Magic

## Problem Statement

Chef has found himself facing an evil witch who has placed a powerful spell on him. To break free, he must undo the spell by transforming the key of the seal the witch has placed upon him.

The key is an alphabetic string of length N. According to the spell's ancient rules, Chef must reverse the order of all vowels in the string while leaving every consonant exactly where it is. The vowels are the letters `a, e, i, o, u` and their uppercase equivalents.

Help Chef perform this transformation and break the witch's spell!

## Input Format

The first line contains a string `S`, representing the key of the seal.

## Constraints

- 1 <= N <= 200000
- `S` contains only uppercase and lowercase English letters.

## Output Format

Print the transformed string after reversing the order of its vowels.
